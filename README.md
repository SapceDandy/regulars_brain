# Regulars Brain

The reference repository for Regulars: its approved concept, planning, specifications, research, maps, models and original documents.

Start with [the current concept](knowledge/current-concept.md), then the [MVP specification](specs/mvp.md), [execution plan](knowledge/execution.md) and [full document index](INDEX.md). AI collaborators should read [AGENTS.md](AGENTS.md) first.

Regulars connects a physical venue to a digital guest experience so people have more reasons to belong, return and bring others. The first pilot combines twelve lockers, membership and seating coordination, and bounded event promotion. The long-term ambition is an AI-operated venue relationship and experience system.

A future [curated social and dating layer](knowledge/long-term-social-and-dating.md) could connect women who choose to join with vetted male members for dates and hosted gatherings across the venue network, strengthening membership value and generating additional venue visits and spending. This is an owner-requested long-term direction; the operating model and outcomes remain to be validated.

## How to use this repository

`knowledge/` is the maintained synthesis. `specs/` describes intended behavior, not verified software. `sources/` preserves originals without changes; older decks and spreadsheets may disagree with the current concept. `searchable/` contains text extracts for retrieval, not replacements for visual layouts or spreadsheet calculations. `catalog/` records provenance and 64 historical Regulars Mandala actions.

The original research is archived as it was recovered; citations and market/legal claims have not been refreshed in this import. No claimed pilot results or implementation readiness are established by this repository. Newly written operational details are labeled as proposed specifications where the owner has not explicitly adopted them.

Run `python3 scripts/validate_knowledge.py` to check original-file integrity, reference links and the action inventory. Record new owner decisions in the decision log, update affected summaries, and retain original documents.
