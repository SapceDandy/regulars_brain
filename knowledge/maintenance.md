# Keeping the brain current

For a new discussion, read current-concept.md and decisions.md first. Add the owner's new decision with date and source, update affected knowledge/spec files, and link new artifacts from INDEX.md. Store originals unchanged; label a revised document as a new dated version and relate it to the earlier one.

Use source-manifest.json to preserve provenance and SHA-256 for originals. Add searchable text when useful, retaining the original file as the authority for layout and calculations. Treat generated summaries as interpretations and keep uncertainty explicit. Record observed tests, signed commitments and actual pilot results separately from planning documents.

This repository is intended as the shared reference when a collaborator opens or queries it. It does not automatically import future conversations or guarantee that every assistant session has loaded it. Ask collaborators to start with README.md and AGENTS.md. Do not store live customer data or credentials in the brain.
